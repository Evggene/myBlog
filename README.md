Приложение Лента постов на Spring mvc (Spring 6). 
База данных h2. Доступ к данным jdbcTemplate. Тесты JUnit 5.
Использует встроенный томкат (org.apache.tomcat.embed), порт 8082.
Собирается как jar и запускается через команду java -jar 'имя'.
Кроме того, можно запустить из intelliJ idea, указав путь к классу Main.
